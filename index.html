GUIDE

ヘルプ

Tarot Spread Canvas の使い方

  1. スプレッドを選ぶ

    使用したいスプレッドを選択します。

  2. テーマ・質問を入力する

    必要に応じて、今回のリーディングのテーマや質問を入力します。入力しなくても使用できます。

  3. カードを配置する

    空いている位置を選んでカードを指定します。PCではドラッグ＆ドロップも利用できます。

    「カードを配置」を使うと、現在のスプレッドへ必要な枚数のカードを78枚から重複なしで自動配置できます。

  4. カードや役割を調整する

    カードの正位置・逆位置や、各位置の役割名などを必要に応じて設定します。

  5. 表示を整える

    背景、表示言語、カード名表記、フォントなどを変更できます。

  6. 完成画像を保存する

    完成画像を確認し、PNGまたはJPEG形式で保存します。

Windows版の使い方

  1. スプレッドを選ぶ

    ワンオラクル、ツーオラクル、ツーマインド、スリーカード、ホースシュー、選択式、ヘキサグラム、ケルト十字から選択します。

  2. カードを配置する

    空の枠を押してカードを選びます。配置済みカードを選ぶと、カード変更、正逆切替、役割名入力、カードを外す操作ができます。

    「カードを配置」は必要枚数を重複なしで自動配置し、「カードをすべて外す」はテーマや役割名を残してカードだけを外します。

  3. 内容と表示を整える

    必要に応じてテーマ・質問や役割名を入力し、背景、表示言語、カード名表記、フォントを変更します。

  4. 完成画像を保存する

    PNGまたはJPEGと解像度を選び、「保存する」を押します。Windowsの保存画面で保存先とファイル名を指定できます。

FAQ

入力したテーマや質問は外部へ送信されますか？

いいえ。

テーマ・質問、カード配置などのリーディング内容は、アプリ内でブラウザ上にて処理されます。

同じカードを複数の位置に配置できますか？

できません。

1回のリーディングでは、同じカードは1枚として扱います。

カードを自動で配置できますか？

できます。

「カードを配置」を使用すると、現在のスプレッドに必要な枚数を78枚から重複なしで配置します。「逆位置を含む」のON/OFFも選択できます。

配置したカードをまとめて外せますか？

できます。

「カードをすべて外す」を使用すると、テーマや役割名などを残したまま、カード配置だけを空にできます。

スマートフォンでも使えますか？

はい。

スマートフォンやタブレットでは、カードをタップして選択できます。ドラッグ＆ドロップは主にPC向けの操作です。

ブラウザを閉じてもリーディング内容は残りますか？

作業内容の永続的な保存は保証していません。

残しておきたいリーディングは、完成画像として保存してください。

保存した画像はどこかへアップロードされますか？

いいえ。

完成画像はブラウザ上で生成して保存します。本アプリがリーディング画像を外部サーバーへ投稿することはありません。

空いているカード位置があっても保存できますか？

できます。

未選択の位置は空のカード枠として表示されるため、スプレッドの形を残したまま保存できます。

このアプリは占い結果を自動で解釈しますか？

いいえ。

Tarot Spread Canvas は、カードの配置・整理・画像作成を行うためのツールです。カードの解釈や鑑定結果の生成は行いません。

インターネット接続がなくても使えますか？

はい。カード画像や背景はアプリ内に収録されているため、オフラインでも利用できます。

入力内容や画像は外部へ送信されますか？

いいえ。テーマ・質問、カード配置、画像生成はこのPC内で処理されます。クラウド保存や外部送信は行いません。

画像はどこへ保存されますか？

「保存する」を押すとWindowsの保存画面が開きます。任意のフォルダとファイル名を指定して、PNGまたはJPEGで保存できます。

カードを自動で配置できますか？

「カードを配置」で、現在のスプレッドに必要なカードを78枚から重複なしで配置できます。「逆位置を含む」も選択できます。

すべてのカードを外せますか？

「カードをすべて外す」で、テーマ・役割名・表示設定を残したままカード配置だけを空にできます。

初回起動時にWindowsの警告が表示されます

このPortable版はコード署名を行っていないため、SmartScreenの確認が表示される場合があります。配布元を確認したうえで起動してください。

WebView2 Runtimeとは何ですか？

Windowsアプリの画面表示に使用するMicrosoftの実行環境です。通常はWindows 10／11に導入済みです。

Tarot Spread Canvas

Tarot Spread Canvas は、タロットのスプレッドをブラウザ上で作成し、完成した配置を画像として保存するためのWebアプリです。

ワンオラクルからケルト十字まで複数のスプレッドに対応し、カードの正逆、役割名、背景、カード名表記などを自由に調整できます。

本アプリはカードの意味や鑑定結果を自動で提示するものではありません。

実際のカードを使ったリーディングの記録や、ブラウザ上でのスプレッド作成を補助することを目的としています。

プライバシー

テーマ・質問、カード配置などのリーディング内容は、アプリ内でブラウザ上にて処理されます。

本アプリから、それらの内容を外部サーバーへ送信する機能はありません。

アカウント登録や、クラウドへのリーディング保存も行いません。

Tarot Spread Canvas for Windows

タロットの配置を作成し、完成画像を保存するWindows向けPortableアプリです。

ワンオラクル、ツーオラクル、ツーマインド、スリーカード、ホースシュー、選択式、ヘキサグラム、ケルト十字の8種類に対応しています。

カードの意味や鑑定結果を自動生成するものではなく、リーディングの配置・記録・画像作成を補助します。

Windows版について

カード画像と背景をアプリ内に収録しているためオフラインで使用できます。画面表示にはMicrosoft Edge WebView2 Runtimeを使用します。

未署名の初期配布版では、初回起動時にWindows SmartScreenの確認が表示される場合があります。

プライバシー

テーマ・質問、カード配置、完成画像の生成はこのPC内で処理されます。外部サーバーへの送信、アカウント登録、クラウド保存は行いません。

免責

本アプリは、タロットカードの配置・記録を補助するツールです。

本アプリの利用によって生じた判断や結果を保証するものではありません。

カード画像について

本アプリでは、Rider–Waite–Smith Tarot をもとにしたカード画像を使用しています。

原作品の著作権が満了している範囲で利用するとともに、本アプリで使用するデジタル画像については、購入元より商用利用を含む利用許諾を得ています。
